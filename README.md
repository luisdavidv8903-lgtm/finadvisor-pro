# FinAdvisor Pro

AI-powered financial advisory platform for personalized investment insights and portfolio management.

## Features

- **Portfolio Analysis** — real-time portfolio tracking with risk/return metrics
- **AI Recommendations** — machine learning-driven investment suggestions based on user risk profile
- **Market Insights** — aggregated news, sentiment analysis, and trend detection
- **Tax Optimization** — tax-loss harvesting suggestions and capital gains tracking
- **Goal Planning** — retirement, education, and custom financial goal projections
- **Multi-Account Support** — consolidate brokerage, retirement, and savings accounts

## Tech Stack

- **Frontend** — React 18, TypeScript, Tailwind CSS, Recharts
- **Backend** — Node.js, Express, Python (ML pipeline)
- **Database** — PostgreSQL, Redis (caching)
- **AI/ML** — scikit-learn, TensorFlow, OpenAI API
- **Infrastructure** — Docker, AWS (ECS, RDS, S3)

## Installation

```bash
git clone https://github.com/luisdavidv8903-lgtm/finadvisor-pro.git
cd finadvisor-pro
npm install
cp .env.example .env  # Configure API keys
npm run dev
```

## API Keys Required

```
OPENAI_API_KEY=your_key
ALPHA_VANTAGE_KEY=your_key
PLAID_CLIENT_ID=your_id
PLAID_SECRET=your_secret
```
